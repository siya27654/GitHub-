Simple Interest Calculator

Project Description

The Simple Interest Calculator is a simple web application that calculates the simple interest and total amount based on the principal amount, annual interest rate, and time period.

Formula

Simple Interest = (Principal × Rate × Time) / 100

Total Amount = Principal + Simple Interest

Inputs

- Principal Amount
- Rate of Interest (%)
- Time Period (years)

Features

- Calculates simple interest instantly
- Calculates the total amount
- Simple and user-friendly interface
- Easy to use and understand

Technologies Used

- HTML
- CSS
- JavaScript

How to Use

1. Enter the principal amount.
2. Enter the annual interest rate.
3. Enter the time period in years.
4. Click the calculate button.
5. The simple interest and total amount will be displayed.
